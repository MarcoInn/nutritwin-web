## Test-Flow
1. User anlegen/auswählen
2. 📷 Direkt Foto aufnehmen (oder Bild hochladen)
3. "Foto analysieren" klicken
4. Vorschlag prüfen/kurz anpassen
5. Meal speichern
6. Daily Report exportieren
